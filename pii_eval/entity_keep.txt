# The scorers measure ORGANIZATION on the over-strip axis: a value the corpus
# ground-truthed keep-expected must survive. Since 2026-08-11 an organization
# survives only by being on a keep list (pii/core/entity_keep.py), so the
# harness needs one naming exactly the merchants its own generator emits —
# otherwise the keep axis would only measure "the shipped file happens to list
# what the generator happens to invent", which is not a property of the tool.
#
# Source of truth for this list: `pii_eval/personas.py::MERCHANTS` plus the
# hard-coded merchants in `pii_eval/txbank.py`. Kept in sync by
# `tests/pii_eval/test_entity_keep_covers_corpus.py`, which fails if the
# generator grows a merchant this file does not keep.
#
# Patterns match case-insensitively anywhere in the value (wrapped in
# \b(?:...)\b), so a bare merchant token also covers the suffixed narrative
