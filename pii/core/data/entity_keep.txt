# Values to KEEP unredacted — one regular expression per line.
#
# Everything NOT matched here is stripped as PII (pii/core/entity_keep.py).
# That is deliberate: an unknown name may be the account holder's own company
# or trust, and an over-strip costs analytical value while an under-strip is a
# breach. Keeping is therefore opt-in, and this file is the opt-in.
#
# What belongs here: banks, insurers, card networks, lenders/aggregators,
# utilities, telcos and the merchants whose names carry the analytical meaning
# of spending data. What does NOT: anything that could be a customer's own
# entity.
#
# Syntax: each line is a regex matched case-insensitively and anywhere in the
# value, and never starting or ending inside a word — so `anz` matches "ANZ
# HIGHETT" but not "ANZAC", and a line may end in `)` or `+`. Use regex where a
# value has spelling variants
# (`st\.?\s*george`). Blank lines and `#` comments are ignored.
#
# Let a line absorb the name's legal form and the words an institution prints
# with it (`national\s+australia\s+bank(?:\s+(?:limited|ltd))?`). A keep match
# exempts exactly what it matches, so an unmatched tail is stripped on its own:
# "QBE Insurance (Australia) Limited" came out as "QBE ORG_3".
#
# [ENTITY_TYPE] starts a section; lines before the first section are
# ORGANIZATION, which is what this file was before it grew sections. A class
# with no section keeps nothing — silence means strip.
#
# Point a run at a different file with --entity-keep FILE or $PII_ENTITY_KEEP.
# `--strip-orgs` ignores the ORGANIZATION section and strips every one of them.

[PHONE_NUMBER]
# Service-number ranges — an institution's published support line, detected
# as PHONE_NUMBER and pseudonymized exactly like a customer's mobile.
#
# SHIPPED DISABLED ON PURPOSE. On a BUSINESS account the holder's own 1300 or
# 1800 line is as identifying as their company name, and this corpus is full
# of business and trust accounts. Enabling the ranges below is a decision to
# make per document set, knowing that. The safer alternative is to list the
# specific institution numbers your documents actually carry, e.g.
#   13\s*13\s*14          # ANZ
#   13\s*22\s*65          # NAB
#
#1300[\s-]*\d{3}[\s-]*\d{3}
#1800[\s-]*\d{3}[\s-]*\d{3}
#13[\s-]*\d{2}[\s-]*\d{2}
