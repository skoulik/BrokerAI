# Image path (strip --image): PaddleOCR is the OCR engine. It needs a
#   paddlepaddle wheel too, chosen per machine and NOT pinned here:
#   - GPU (paddlepaddle-gpu, CUDA) is the fast path; on Windows it cannot

#     pull in real torch transitively, so removing GLiNER2 did NOT make the
#     pipeline torch-free (measured 2026-08-09). See pii/core/TODO.md.
#   - CPU (paddlepaddle) works in-process but is slow; see pii/core/ocr_paddle.py.
